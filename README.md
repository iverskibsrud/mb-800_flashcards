# MB-800 Flashcards

Read-only flashcards with a simple GUI for browsing, flipping, and shuffling cards.

## GitHub Pages

Recommended domain for this repository:

- `https://iverskibsrud.github.io/mb-800_flashcards/`

To publish:

1. Push this branch to GitHub.
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` (or your default branch) and folder `/ (root)`.
5. Save and open the URL above.
